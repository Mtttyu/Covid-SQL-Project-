A SQL-based data analysis project focused on exploring COVID-19 cases, deaths, population data, and vaccination progress across different countries and regions.

Key Objectives & Analysis

Analyzed COVID-19 death and vaccination data using SQL.
Combined COVID-19 deaths and vaccination datasets using JOIN operations.
Calculated rolling cumulative vaccinations for each location using SQL Window Functions.
Compared vaccination progress with total population to analyze vaccination coverage.
Created a reusable SQL VIEW to organize and simplify the analysis results.
Applied filtering and data validation to exclude records with missing or invalid values.
